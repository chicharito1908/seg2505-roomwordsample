# RoomWordSample — SEG2505

## Description du projet

RoomWordSample est une application Android développée en Java avec Android Studio dans le cadre du laboratoire SEG2505 de l'Université d'Ottawa.

L'application permet à l'utilisateur d'ajouter des mots, de les enregistrer dans une base de données locale et de consulter la liste des mots enregistrés.

## Technologies utilisées

- Java
- Android Studio
- Room Database
- RecyclerView
- ViewModel et LiveData
- Gradle

## Fonctionnalités

- Affichage d'une liste de mots.
- Ajout de nouveaux mots à l'aide du bouton +.
- Enregistrement des mots dans une base de données Room.
- Mise à jour de la liste des mots enregistrés.

## Exécution

1. Ouvrir le projet dans Android Studio.
2. Synchroniser les fichiers Gradle.
3. Démarrer un émulateur Android.
4. Exécuter l'application.
5. Ajouter un mot et vérifier son affichage dans la liste.
